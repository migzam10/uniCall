# Avatar 3D y biblioteca de animaciones (Fase 6)

- `models/`      → Modelo 3D del avatar humano realista.
- `animations/`  → Biblioteca de animaciones LSC (una por seña/frase documentada).
- `metadata/`    → Metadatos de cada animación: nombre, significado, categoría, versión, estado.

Prioridad definida en la especificación: precisión del movimiento > claridad
de las señas > sincronización > naturalidad > rendimiento.
